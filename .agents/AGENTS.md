# Antigravity Assistant Workspace Guidelines

## Developer Profile & Preferences
- **Beginner Level**: The developer is a beginner in React Native and backend integration. 
- **Educational Explanations**: Explain the "why" and "how" behind every step, file structure, configuration, and function.
- **Solution Justification**: For every proposed change or implementation decision, clearly provide the justification, alternate paths (if any), and the rationale behind the chosen solution.
- **Formatting**: Keep guides structured, clear, and focused on learning.
